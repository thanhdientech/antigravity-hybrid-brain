## 🌟 TỔNG QUAN HỆ THỐNG

Dự án **`create and edit video`** hợp nhất 5 công nghệ biên tập và lập trình video mạnh nhất thế giới hiện nay thành một quy trình sản xuất khép kín:

1. **Remotion** (React/TypeScript GPU): Làm video tin tức, bảng điều khiển UI, bản đồ vệ tinh GPS, bảng so sánh đối kháng và hiệu ứng âm thanh karaoke.
2. **Motion Canvas** (TypeScript Web Engine): Diễn họa thuật toán, khoa học máy tính và mạng nơ-ron tương tác trực tiếp trên trình duyệt.
3. **Manim** (Python 3Blue1Brown): Đỉnh cao hình học biến hình (morphing) và các công thức toán học LaTeX chuẩn điện ảnh.
4. **Auto-Editor** (Python/CLI): Cắt bỏ khoảng lặng tự động cho Podcast, Talkshow, Shorts chỉ bằng 1 dòng lệnh.
5. **Editly** (Node.js JSON Spec + Shaders): Ghép nối video hàng loạt tự động từ file JSON khai báo, hỗ trợ chuyển cảnh GLSL mượt mà.
